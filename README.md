# 🍵 品茶录 · 第一期（MVP）

微信小程序原生开发 + 微信云开发（云数据库）。闭环：冲泡计时 → 品饮记录 → 回看。

## 云端模式（默认，`USE_CLOUD: true`）

正式环境 `cloud1-d8g1uyjpxfd6dbd7f`，写死在 `config/env.js` 的 `ENV_ID`；AppID `wxb468114b66cd1490`（个人主体）。

1. 云开发控制台 → 数据库，4 个集合，权限都是 **仅创建者可读写**：
   `teas`、`wares`、`brews`、`tags`
2. 索引（与 `utils/db.js` 的查询对应）：
   - `teas`：`_openid` 升序 + `createdAt` 降序（茶柜分页拉取）

6. 真机预览验证震动、提示音、常亮、切后台重算。

### 本机数据搬上云（`utils/migrate.js`）

原型阶段本地模式的数据（本地存储 `localdb_*` + 用户目录里的照片）在切到云端后首次启动时自动搬上云，演示数据（`mock_`）也照搬。首页显示“本机数据搬上云”遮罩，搬完再加载。逐条写，每成功一条记下 本地 `_id` → 云端 `_id`（`migrateMap`），断网中断下次打开接着搬，不会重复；冲泡记录的 `teaId` / `wareIds`、待同步队列、进行中冲泡、计时页器柜茶器偏好里的 `_id` 一并换成云端的；茶的 `lastBrewedAt` / `lastRating` 按冲泡记录重算。搬完删掉本地库和旧缓存，照片原文件留在本机。每台用过本地模式的设备（开发者工具模拟器、真机）各自搬一次。

## 本地模式（原型，`USE_CLOUD: false`）

不需要云开发：数据存本机本地存储，照片存小程序本地用户目录（`utils/localCloud.js` 模拟了 `db.js` 用到的云数据库 / 云存储接口）。`MOCK_DATA: true` 时首次启动会写入一柜演示数据（`utils/mock.js`：24 款茶覆盖六大茶类与普洱、八个产地，15 件茶器，约 90 场近两个半月的冲泡记录（带风味轮描述词、专业审评、所用茶器），_id 以 `mock_` 开头，与自己录入的数据并存）；想重新生成就在开发者工具里清除数据缓存。云端模式下 `MOCK_DATA` 不生效，正式版保持 `false`。

## 语音记录（品茶评论）

- 计时页“开始泡茶”后默认自动开始录音，把大家对这款茶的评论逐段记下来：点「结束一段」停下当前段并转成文字，再弹窗问“这段是谁说的”，记完后自动开始下一段。
- 转写走自建云函数：录音（`wx.getRecorderManager`）→ 上传云存储 → 云函数 `asr` 调腾讯云「一句话识别」返回文字，单段最长 60 秒；云函数未部署 / 转写失败 / 本地模式时，自动弹窗让你手动补写这段说了什么。
- 点「结束」时会把正在录的最后一段也收尾成一条评论，然后进入汇总页：
  1. 把多人的评论整理成总评：先用“按说话人逐条列出”的方式垫底，再后台调用微信云开发内置大模型（混元 hy3）整理成通顺的整体评论，按香气 / 滋味 / 汤色 / 回甘与韵味 / 叶底 / 总体印象分段；AI 不可用/失败时保留拼接版；每条评论也能点开改说话人/内容或删除。
  2. 自动检查大家还没谈到的方面（香气 / 滋味 / 汤色 / 回甘与韵味 / 叶底 / 评分），在顶部“补全提醒”里列出，点一下直接滚动到对应表单补填。
- `brews` 新增可选字段 `voices`：`[{ id, speaker, text, durationMs }]`，与原有 `tags` / `review` / `rating` / `note` 一起保存，旧记录没有该字段时按空数组处理。

### 语音转文字需要做的事（真机 / 正式版）

1. 开通腾讯云「语音识别 ASR」服务（控制台：cloud.tencent.com → 语音识别）。
2. 在开发者工具里右键 `cloudfunctions/asr` →「上传并部署：云端安装依赖」；首次会提示选择云环境，选本项目已有的 `cloud1-d8g1uyjpxfd6dbd7f`。
3. 在云开发控制台 → 云函数 → `asr` → 配置 → 环境变量，添加 `TENCENT_SECRET_ID` / `TENCENT_SECRET_KEY`（建议用腾讯云子账号，只授权 ASR 权限）。
4. 小程序后台的“用户隐私保护指引”需新增声明：
   - 信息类型「麦克风」，用途：品茶时录音并转成文字，用于整理大家对这款茶的评论。
   - 录音会上传到本项目云存储、并由云函数调用腾讯云语音识别进行转写，转写后即删除音频，不长期保存语音。
5. 真机上首次开泡录音时会弹麦克风授权，拒绝后录音不可用（可关闭“语音记录”开关，改回手动记一笔）。

> 没部署云函数时也能用：录音照常、转不出文字时会弹窗让你手动补写这段说了什么，只是少了“自动转文字”。

## 时令推荐规则（参考李辉《茶道经》）

- 六茶对六经：太阳绿茶、太阴白茶、少阴黄茶、少阳红茶、阳明青茶、厥阴黑茶。
- 时辰：7–9 点绿茶，9–11 点白茶（脾经当令），11–13 点黄茶（心经当令），13–15 点红茶（小肠经当令），15–17 点青茶，17 点后黑茶；白茶 24 小时皆可。
- 季节：春红茶、夏绿茶、秋青茶、冬黑茶，季节之交黄茶，白茶四季皆宜；一日喝茶品种不宜超过三种，临睡前不宜过量。
- 补全约定：5–7 点并入清晨；21 点后单列“夜里”；季节以四立划分，四立前 18 天算季节之交；生普随普洱归黑茶。
- 首页每类茶标“品性”（口感与适宜的场合），不写保健功效；界面注明仅作饮茶雅趣参考，不作医疗建议。

## 与 PRD 的几处落地约定

- `teas` 额外冗余了 `lastRating`（最近一次冲泡的评分），用于首页卡片展示评分；与 `lastBrewedAt` 一起在保存、编辑、删除冲泡时按该茶最新一条记录重算。
- `teas` 新增可选字段：`photos`（云存储 fileID 数组，第一张为封面，最多 6 张）、`sourceType`（`buy` 自购 / `gift` 茶友赠 / `event` 茶会活动 / `other`）、`sourceName`（店铺、卖家或赠送人）、`acquiredAt`（入手日期）。照片在保存时才上传；编辑中移除的照片、删除茶时的照片会从云存储一并删除。
- 首页推荐只看最近 100 场冲泡（含未同步），本地缓存 10 分钟，有冲泡增删改时立即失效。
- 茶类新增 `heicha` 黑茶（茯砖、千两、六堡）；`cls` 标茶柜“品类”归属，生普、熟普单列为普洱。
- `wares` 集合：`name`、`kind`、`material`、`capacityMl`、`maker`（作者 / 窑口）、`sourceType` / `sourceName`、`acquiredAt`、`photos`、`forClasses`（宜泡，六大茶类 + 普洱的 code）、`note`、`retired`（收起不用）。
- `brews` 新增 `wareIds`（本场用的器柜茶器，顺序为主泡器、公道杯、品茗杯）与 `review`（`{ liquor, clarity, scores: { aroma, lasting, sweet, umami, body, huigan, shengjin, houyun, bitter, astringent }, leaf: [] }`，都可缺省）。香气描述词仍存 `tags`，旧的风味标签照常显示；自定义描述词的 `group` 改为风味轮亚类名。每一泡的 `steeps[].tastes` 另存滋味描述词（甘甜 / 鲜爽 / 醇厚 / 回韵 / 苦 / 涩 / 酸 / 淡薄），与香气分开记录、逐泡可改；每一泡的 `steeps[].review` 另存该泡的专业审评（汤色 / 清亮度 / 十项强度，无叶底）。整场 `brews.review` 由每泡审评自动汇总（汤色清亮度取最常见、强度取各泡平均），叶底只在整场记录，也可手动调整或“按每泡重新汇总”。茶详情的“风味画像”取各场审评平均值画雷达图，并按风味轮大类统计香型。
- `teas` 新增可选字段 `variety`（品种）、`shelves`（自定义分组名数组，一款茶可在多个分组，分组名不单独建集合，从所有茶里汇总）。茶柜“产地”分组取 `origin` 开头的省份，所以产地建议以省份开头填写；“商家”分组按 `sourceName`，茶友赠的标“（赠）”。
- `teas` 新增可选字段 `finished`（已喝完）：在茶编辑页或茶柜长按切换；已喝完的茶不推荐、不出现在计时页选茶列表，仍可在茶柜“已喝完”里查看。
- `brews.rating` 用 `0` 表示未评分（编辑时无法"省略"字段）。
- 手动补记的 `steeps` 只含泡序号 `{ n }`，没有时长（避免编造数据）。
- 进行中冲泡、预置参数、缓存、待同步队列都在本地；整场在汇总页保存时才写云端。写失败进入待同步队列，列表中标"未同步"，下次打开小程序或点击首页提示条自动重试。
- 删除茶时冲泡记录保留，`teaId` 不变；记录编辑页的茶名显示为“已删除的茶”。

## 茶具搭配与配乐

- 计时页开泡前按茶类推荐两套茶具（第一套为推荐），附样品插画、器具清单和理由；计时中点顶部“茶具”可再看。插画只示意器型，不对应具体商品。
- 配乐为程序合成的原创古琴风小品（`design/gen_music.py`，固定随机种子），不是传世古曲的录音，可随包发布。想换正版录音的古曲，把 `config/music.js` 里的 `src` 改为云存储 fileID 或 https 地址（https 需配置 request 合法域名）。
- 茶具搭配参考、配乐、器柜茶器的选择按茶类记在本地 `brewPrefs`；“不放”对所有茶类生效。搭配参考与配乐存在进行中冲泡里（`wareId`、`music`），不写入冲泡记录；器柜茶器 `wareIds` 随记录保存。
- 计时中配乐循环播放，出汤提示音响起时压低 2.5 秒；离开计时页或切后台时暂停，回来继续。iOS 静音键开着时配乐不响。
- 5 首配乐约 1MB，注意主包 2MB 上限；后续如需更多曲目，建议放云存储。

## 已知限制

- 上传照片需要网络；离线时保存带新照片的茶会失败。
- 新建茶需要网络；离线时无法新建，可先只选茶类开泡，之后在汇总页补选已有的茶。
- 编辑/删除**已同步**的冲泡记录需要网络；待同步的记录可离线编辑。
- 小程序切后台后无法可靠震动提醒（平台限制），计时页已提示“请保持在前台”；回到前台会按实际流逝时间重算。
