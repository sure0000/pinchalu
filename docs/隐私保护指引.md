# 品茶录 · 用户隐私保护指引（填写稿）

填写位置：小程序后台 → 账号设置 → 服务内容声明 → 用户隐私保护指引 → 去完善。
依据：代码里涉及隐私的接口有 `wx.chooseMedia`（`pages/tea-edit`、`pages/ware-edit`，相册 / 拍照选图片）和语音记录（`pages/timer`，麦克风录音，上传云存储后由云函数调腾讯云语音识别转写，转写后即删除音频）。以后新增其他隐私接口，要先回来补声明，否则接口会调用失败。

## 1. 处理的用户信息

| 信息类型（下拉选择） | 用途（“为了……”后面的填空） |
| --- | --- |
| 选中的照片或视频信息 | 为你的茶叶和茶器添加照片，作为茶柜、器柜里的封面和详情页配图 |
| 麦克风 | 品茶时录音，把大家对这款茶的评论转成文字，整理成整体评论 |

> 语音转写：录音会临时上传到本项目云存储，由云函数 `asr` 调用腾讯云「语音识别 ASR」转成文字，转写完成后立即删除音频，不长期保存语音。

## 1.1 第三方信息处理说明

语音转写使用了腾讯云「语音识别 ASR」服务（第三方，腾讯云计算（北京）有限责任公司）。在用户隐私保护指引里，需要把腾讯云语音识别列为处理用户信息（语音）的第三方，并告知用户语音仅用于转写、转写后即删除。

## 2. 存储期限

选“开发者承诺，除法律法规另有规定外，开发者对你的信息的保存期限应当为实现处理目的所必要的最短时间”。

## 3. 补充文档（选填，可整段粘贴）

品茶录是个人饮茶记录工具。你在品茶录中录入的茶叶、茶器、冲泡记录、品饮笔记、风味描述与评分，以及你为茶叶、茶器添加的照片，保存在本小程序的微信云开发数据库和云存储中，按你的微信账号（OpenID）隔离，仅你本人可读写，开发者不会将其用于展示给他人、广告推送或其他用途，也不会提供给任何第三方。

进行中的冲泡计时、冲泡偏好和部分缓存只保存在你的手机本地。

你可以随时在小程序内编辑或删除茶叶、茶器和冲泡记录；删除茶叶或茶器时，其照片会同时从云存储中删除。如需一次性删除全部数据，可通过下方联系方式联系开发者处理。

首页的时令、时辰宜饮与“品性”说明仅作饮茶雅趣参考，不构成医疗或健康建议。

## 4. 联系方式

至少填一项：邮箱 / 电话 / 微信号（填你愿意公开给用户的那个）。
